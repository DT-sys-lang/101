## 2. 证据登记规则

每项必须填写受控证据链接或工作区相对路径、执行时间、环境 ID、责任人和结果。不得写入密码、Token、Cookie、私钥、完整连接串、HMAC、`PGPASSFILE` 或敏感 `.env` 值。

允许的状态：`通过`、`待验证`、`缺失`、`阻断`。任何 `待验证`、`缺失` 或 `阻断` 都禁止将本审批包改写为 Go。
